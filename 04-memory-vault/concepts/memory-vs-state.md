# Memory vs state

## State

State is what the system needs right now to continue the task.

Examples:

- current goal
- current tool result
- files created in this run

## Memory

Memory is what the system keeps over time.

Examples:

- lesson notes
- repeated mistakes
- saved preferences
- project decisions

## Why it matters

Agents become easier to debug when short-term state and long-term memory are treated differently.
