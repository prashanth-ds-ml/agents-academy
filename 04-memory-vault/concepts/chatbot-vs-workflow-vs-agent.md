# Chatbot vs workflow vs agent

## Chatbot

A chatbot mainly answers questions.

## Workflow

A workflow follows predefined steps in a fixed order.

## Agent

An agent observes, decides, acts, and uses the result to choose the next step.

## My explanation

- A chatbot talks
- A workflow follows instructions
- An agent makes bounded decisions inside a loop
