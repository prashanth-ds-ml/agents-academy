# Agent Academy

This is your learning workspace for studying, building, remembering, and publishing around AI agents.

Open this folder directly as an **Obsidian vault** for the best reading and linking experience.

## Study flow

1. Read the current lesson in `01-lessons`.
2. Build the matching mini-project in `02-projects`.
3. Capture ideas and mistakes in `04-memory-vault`.
4. Convert insights into public drafts in `05-blog`.

## Folder map

- `00-dashboard` - roadmap and progress
- `01-lessons` - lessons, notes, and exercises
- `02-projects` - hands-on builds
- `03-practice` - daily and weekly practice
- `04-memory-vault` - Obsidian-friendly memory notes
- `05-blog` - ideas and drafts for learning in public
- `06-resources` - setup guides and references
- `07-templates` - reusable note templates

## Obsidian flow

Start from [[HOME]].

- Use [[00-dashboard/progress-tracker]] to see current focus
- Use [[00-dashboard/next-steps]] when resuming after a break
- Use `04-memory-vault` for concept notes and reflections
- Use `07-templates` when creating new learning notes
